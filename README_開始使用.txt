AI 互動作品製作與網站部署｜課堂教學套件
作者：國立清華大學 數理教育研究所 吳智鴻教授

GitHub 專案目標：profchwu/webdeployment
上線網址（啟用 GitHub Pages 後）：https://profchwu.github.io/webdeployment/

使用說明：將本目錄內的所有檔案與 assets、student-game 資料夾一併上傳到儲存庫根目錄。
GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。
請勿只上傳 ZIP；網站的 index.html 應位在根目錄。
