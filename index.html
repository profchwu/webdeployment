第一部分｜如何啟動 AI 互動環境（真實軟體操作截圖）

閱讀方式：每張圖片都是原始產品介面的真實截圖，不是 AI 生圖；紅框是原截圖作者的標註。介面可能隨版本改變，請參考圖片下方的來源及操作文字。

① Gemini Canvas｜從工具選單啟動 Canvas

  1. 開啟 gemini.google.com 並登入。
  2. 在提示詞欄旁點選 「＋」或「工具（Tools）」，依目前介面位置為準。
  3. 在工具清單點選 Canvas，確認提示框顯示 Canvas 模式。
  4. 輸入「幫我製作可以預覽的互動式數學測驗 HTML」，按送出。
  5. 生成後會出現 Canvas 編輯／Preview 畫面；可再修改與取得程式碼。

Google 官方操作說明：開啟 Canvas。

② Claude Artifacts｜確認功能可用並啟動

  1. 開啟 claude.ai 並登入。
  2. 進入 Settings → Capabilities，確認 Cloud code execution and file creation 已開啟（Artifacts 的必要條件）。
  3. 可在 Claude 對話直接輸入「請建立可以互動的數學遊戲 Artifact」，或從側欄的 Artifacts 入口開始，依帳號顯示的選項選擇。
  4. 在右側 Artifact 視窗使用 Preview / Code 測試及修改，再取得程式碼部署。

官方 2026 說明：What are artifacts and how do I use them?；免費帳號可以建立 Artifacts。

③ ChatGPT｜建立程式碼並預覽

ChatGPT 的 Code／Preview 功能與 Gemini Canvas、Claude Artifacts 不完全相同。此處暫不使用未取得來源的假畫面。

  1. 開啟 ChatGPT。
  2. 輸入：「建立可離線執行、含 HTML/CSS/JavaScript 的互動數學遊戲，並提供可預覽的程式碼」。
  3. 使用顯示的 Code / Preview 檢視結果；若未提供預覽，將程式碼另存 index.html 並用瀏覽器開啟。

第三部分｜一步一步部署

GitHub Pages

  1. 建立 Public repository。
  2. 上傳根目錄 index.html。
  3. Settings → Pages。
  4. Deploy from a branch。
  5. main + /(root) → Save。
  6. 訪問 username.github.io/repo/。
官方圖文教學 ↗

Netlify

  1. 登入 Netlify。
  2. Add new project → Deploy manually。
  3. 拖曳含 index.html 的整個資料夾。
  4. 等待發布並複製 netlify.app 網址。
  5. 用無痕視窗測試。
官方圖文教學 ↗

Cloudflare Pages

  1. 登入 Cloudflare dashboard。
  2. Workers & Pages → Create。
  3. 選 Direct Upload／拖放上傳。
  4. 上傳資料夾或 ZIP。
  5. Deploy，開啟 pages.dev 網址。

建議 AI 提示詞：

請製作繁體中文的互動式數學闖關遊戲，產生可離線執行的單一 index.html，內嵌 CSS 和 JavaScript。至少 5 題四選一、即時計分、提示、重新開始，支援手機。不可使用外部 CDN 或暴露 API key。

驗收：使用無痕視窗、測試所有按鈕、確認手機顯示、檢查公開網址與原始碼。
