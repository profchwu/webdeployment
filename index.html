04 · HANDS-ON TUTORIAL

六套逐步圖文操作

選擇平台查看逐步流程。畫面是依官方操作路徑重繪的教學示意，並非平台當日實際截圖；每組都附官方圖文教學連結。

Gemini Canvas：詳細操作步驟

  1. 進入 gemini.google.com，登入 Google 帳號。
  2. 開啟 Canvas，貼上課堂提示詞，要求單一檔 index.html。
  3. 在 Canvas 預覽並測試每個按鈕、答題與手機版。
  4. 若需 Gemini 內分享：按「分享及匯出」建立分享連結。
  5. 若需獨立免登入網站：複製完整 HTML 程式碼，存成 index.html，改用靜態部署。
開啟官方圖文截圖／操作文件 ↗

ChatGPT：詳細操作步驟

  1. 進入 chatgpt.com，請求「產生完整單檔 index.html」。
  2. 確認回答中的 HTML 程式碼區塊，可切換 Code／Preview 時先預覽。
  3. 修改提示詞，要求修正答題、計分、手機適配等功能。
  4. 複製程式碼並另存為 index.html，先在瀏覽器直接開啟。
  5. 以 GitHub Pages、Netlify 或 Cloudflare Pages 公開部署。
開啟官方圖文截圖／操作文件 ↗

Claude Artifacts：詳細操作步驟

  1. 進入 claude.ai，提出「建立互動式數學遊戲 Artifact」。
  2. 右側檢視 Artifacts 作品，操作 Preview 測試功能。
  3. 切換到程式碼檢視，複製可獨立運作的 HTML／CSS／JS。
  4. 免費帳號不要依賴新版 Artifact 分享連結；改將程式碼另存 index.html。
  5. 到免費靜態網站平台部署，將網址交給同學測試。
開啟官方圖文截圖／操作文件 ↗

GitHub Pages：詳細操作步驟

  1. GitHub 註冊登入，選 New repository，建立 Public 儲存庫。
  2. Add file → Upload files，上傳 student-game/index.html（必須位於根目錄）。
  3. 點 Settings → Pages → Build and deployment。
  4. Source 選 Deploy from a branch；Branch 選 main、/(root)，按 Save。
  5. 等待部署完成，開啟 https://帳號.github.io/儲存庫名稱/ 驗收。
開啟官方圖文截圖／操作文件 ↗

Netlify：詳細操作步驟

  1. 登入 app.netlify.com，開啟 Add new project。
  2. 選 Deploy manually，將包含 index.html 的 student-game 資料夾拖放上傳。
  3. 網站發布後複製自動產生的 *.netlify.app 網址。
  4. 以無痕視窗確認不用登入也能玩。
  5. 更新程式後，再到該網站的 Deploys 重新部署。
開啟官方圖文截圖／操作文件 ↗

Cloudflare Pages：詳細操作步驟

  1. 登入 dash.cloudflare.com，進入 Workers & Pages。
  2. 選 Create application → Pages／Drag and drop your files。
  3. 輸入專案名稱，上傳包含 index.html 的 student-game 資料夾或 ZIP。
  4. 按 Deploy site，獲得 *.pages.dev 網址。
  5. 無痕視窗測試，再到專案建立新的 deployment 更新作品。

06 · TROUBLESHOOTING

最容易遇到的問題

網址開啟顯示 404

檢查 index.html 是否位於網站發布根目錄；GitHub Pages 是否選 main + /(root)，以及是否等待部署完成。

別人看不到 AI 作品

AI 預覽和正式部署是兩回事。免費 Claude 的新版 Artifact 分享有限制；請用 HTML + 靜態主機公開作品。

AI 功能部署後失效

外部 AI、資料庫與即時語音一般需要伺服器、API 或驗證；靜態網站託管並不提供免費生成式 AI 推論。
